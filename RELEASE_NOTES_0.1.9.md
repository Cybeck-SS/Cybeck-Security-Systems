# Cybeck Security Systems v0.1.9

- Added an AnyDesk connection launcher to Remote Systems. Enter a 9–10 digit AnyDesk ID or alias and select Connect with AnyDesk to start a request in an installed AnyDesk client.
- Added a button to open AnyDesk's official Windows download page when a user needs to install it independently.
- Kept AnyDesk authentication, approval, screen viewing, control, and updates in AnyDesk. Cybeck does not store a remote password or install AnyDesk.

AnyDesk is not included in this installer. The user must install it on both computers and follow AnyDesk's license and approval flow. Cybeck Connect's own encrypted viewer and pairing code remain planned. This Cybeck installer is unsigned; Windows Application Control blocked packaged-app testing on the build machine. Automated tests pass.

# Cybeck Security Systems v0.1.3

This release brings the Network Monitor and Operations work from phases 1–7 into the Windows desktop build.

- Added session statistics, event history filters, outage and recovery tracking, and connection reliability measurements.
- Added read-only connection observations and security events for network changes, DNS failures, unusual ports, and repeated connection attempts.
- Added incident investigation and resolution workflows, optional confirmed outbound IP blocking, and PDF or JSON incident report export.
- Added encrypted local event and incident history, daily summaries, and the Operations dashboard.
- Preserved the existing network globe, latency graph, diagnostics, Quick Actions, and GitHub updater.

Security observations are indicators for review, not malware verdicts. Firewall actions require explicit in-app confirmation and may need administrator access.

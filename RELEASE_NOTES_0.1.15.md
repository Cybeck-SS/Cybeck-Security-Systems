# Cybeck Security Systems v0.1.15

## Vault profile management

- Removed the decorative People, Data, Ideas, Safer, and Together wording because it had no application function.
- Replaced the profile card row with a compact dropdown so additional profiles do not crowd the Vault login screen.
- Added Create profile and Delete selected controls.
- Profile deletion requires the selected profile password and an explicit confirmation.
- Deleting an unlocked profile clears its active Vault session.
- Updated the in-app Current Release panel and Release History through v0.1.15.

## Verification

- All automated tests pass.
- Existing Network Monitor, Operations, Tasks, Notes, remote access, incidents, Vault authentication, and updater behavior remain available.
